The following identify the official project and are reserved from the GPL

- The SummonersVault name when used as a product or service name.
- The SummonersVault hexagonal S logo and application icon.
- Official installer, shortcut, release, and application branding.

## Permitted references

You may:

- Refer to SummonersVault accurately in articles, reviews, issue reports, and
  technical documentation.
- Link to the original project at
  `https://github.com/RVerheggen/SummonersVault`.
- State that another product is "based on SummonersVault" or "derived from
  SummonersVault" when that statement is accurate and is not presented as the
  product name.
- Identify an exact, unmodified copy of official source code or an official
  release as SummonersVault, provided its origin is made clear.

## Modified distributions and forks

A modified application or independently published build must:

- Use a clearly different user-facing product name and application icon.
- Avoid using SummonersVault as its primary executable, installer, package,
  website, store-listing, or service name.
- Remove or replace official update endpoints, package identifiers, and other
  settings that could make the modified application appear to receive official
  SummonersVault releases.
- Clearly state that it is an independent project and is not endorsed,
  supported, reviewed, or published by the SummonersVault project.
- Preserve the notices and source-code obligations required by GPLv3.
- Remain independently responsible for security, support, Riot registration,
  Riot policies, and all other legal or operational obligations.

Internal source namespaces and factual compatibility references do not need to
be renamed when they are not used to present the modified product as an
official SummonersVault release.

Permission to use the official name or branding beyond this policy requires
prior written permission from the project owner.

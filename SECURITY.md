# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose vault data, credentials, League Client tokens, or update infrastructure. Use GitHub private vulnerability reporting when it is enabled for this repository.

Include the affected version, reproduction steps, expected impact, and any suggested mitigation. Do not include real account credentials, vault files, database keys, or League Client lockfiles in a report.

## Supported versions

Until the first stable release, only the latest published preview is supported. Security fixes will be released through the normal GitHub Release and in-app update process.

## Distribution trust

SummonersVault releases are currently unsigned. Windows may display a SmartScreen warning. Release checksums and GitHub build provenance attestations help verify that an artifact was produced by this repository's release workflow, but they do not prove that the software is free of vulnerabilities.

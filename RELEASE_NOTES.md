# SummonersVault 0.1.0

Initial public preview of the local encrypted account vault and read-only League Client companion.

- Store multiple encrypted League account credentials with roles and notes.
- Synchronize League identity, ranks, collections, wallet, match history, and crafting inventory.
- Search and filter accounts, champions, skins, ranks, and roles.
- Export and merge encrypted `.svault` backups.
- Install or run portably on Windows 11 x64 with user-approved update checks.
